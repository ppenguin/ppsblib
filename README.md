# `ppsblib`

Personal libraries for use with SilverBullet.

Maybe to be PR/upstream if they ever mature and are generally useful.

- [SilverInk](src/SilverInk/README.md): a SilverBullet handwriting plug with
  persistent vector strokes, recovery, and offline block review/insertion.
- [QuickAccess](src/QuickAccess/QuickAccess.md): a top bar quick
  actions button for touch navigation.

For browser testing on this host or the LAN, use the
[local SilverBullet test Space](_test/README.md). To keep the published library
index current, use the [repository update skill](skills/update-ppsblib-repository/SKILL.md).
